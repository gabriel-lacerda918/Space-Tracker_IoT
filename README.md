# SpaceDebris Monitor Academic

## Tema
Monitoramento Espacial com Visão Computacional.

## Objetivo
Simular um sistema de observação utilizado por satélites para detectar objetos,
estimar distância e avaliar risco de colisão.

## Funcionalidades

- Captura de vídeo em tempo real
- Detecção de objetos utilizando YOLOv8
- Reconhecimento automático de classes
- Estimativa de distância
- Medição da largura do objeto em pixels
- Indicador de risco de colisão
- Exibição de FPS
- Calibração da câmera

## Estrutura

src/
├── main.py
└── calibration.py

## Instalação

pip install -r requirements.txt

## Execução

python src/main.py

## Calibração

python src/calibration.py

## Relação com a GS

A solução simula sistemas empregados em:

- Monitoramento orbital
- Rastreamento de detritos espaciais
- Sensoriamento remoto
- Observação terrestre por satélites
- Sistemas autônomos de inspeção espacial
